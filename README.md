# ESP32 双板 iPhone 网页遥控器

用两块 ESP32 打造一个可以**通过手机浏览器远程操控 iPhone** 的遥控器。打开网页，就能在被控 iPhone 上移动光标、精准点击任意位置、滚动、输入文字、触发常用手势——支持**屏幕绝对定位**(点哪跳哪),而不只是相对移动。

采用**双板架构**:一块专门跑 WiFi 网页服务，一块专门跑蓝牙 HID，两块之间用串口通信。两个射频(WiFi / 蓝牙)物理隔离，从根本上避免了单板上 WiFi 与 BLE 共存时的相互干扰、内存不足和卡死问题，适合长期稳定运行。

> 📖 **第一次用 Arduino / 不熟悉烧录环境?** 请先看 [Arduino_Readme.md](./Arduino_Readme.md),里面有从零安装 Arduino IDE、ESP32 支持包、依赖库到烧录的完整图文步骤。

---

## 功能特性

- **绝对定位**:输入屏幕百分比或在映射区点选，光标直接跳到 iPhone 屏幕对应位置
- **精准点击 / 移动并点击**:在指定绝对坐标处点击，可用来打开 App、点按界面元素
- **触控板**:拖动移动光标、轻点左键、滚轮滚动
- **八方向微调 + 步长切换**:像素级微调光标位置
- **文字输入**:英文文字直接输入到被控设备
- **常用按键**:方向键、Enter、Esc、Tab、退格、翻页(PgUp/PgDn/Home/End)
- **iOS 手势**:回主屏、Spotlight 搜索、切换 App
- **断线自动重连**:蓝牙断开后自动重新广播，iPhone 可自动重连，无需手动重启
- **网页零安装**:任意手机 / 电脑浏览器打开即用，界面自适应移动端

## 架构原理

```
   ┌─────────────┐      WiFi / HTTP       ┌──────────────┐
   │  你的手机    │ ────────────────────▶ │   A 板       │
   │ (浏览器面板) │                        │ WiFi 网关    │
   └─────────────┘                        └──────┬───────┘
                                                 │ 串口 (UART)
                                                 │ A板D17 → B板D16
                                                 ▼
                                          ┌──────────────┐
                                          │   B 板       │
                                          │ BLE 键鼠     │
                                          └──────┬───────┘
                                                 │ 蓝牙 (BLE HID)
                                                 ▼
                                          ┌──────────────┐
                                          │  被控 iPhone │
                                          └──────────────┘
```

**A 板(WiFi 网关)**:只跑 WiFi + 异步网页服务，不碰蓝牙。收到网页指令后，通过串口原样转发给 B 板。因为不开蓝牙，内存宽裕、射频干净，网页服务稳定。

**B 板(BLE 键鼠)**:只跑蓝牙 HID，不碰 WiFi。从串口接收 A 板转发来的指令，解析后执行真正的键鼠 / 绝对定位操作。因为不开 WiFi，内存全给蓝牙、射频独占，长期稳定。

**为什么用两块板?** 单块 ESP32 同时跑 WiFi 和 BLE 时，两者共用一颗 2.4GHz 射频、争抢内存，会导致网页卡死、蓝牙被挤断、内存不足无法启动等一系列问题。双板把两个射频彻底隔离，各司其职，是长期可靠运行的最优解。

## 二、两板接线

用杜邦线连接两块板的串口(Serial2)和地线，共 **2 根线**:

| A 板 (WiFi 网关) | 方向 | B 板 (BLE 键鼠) | 作用 |
|------------------|------|------------------|------|
| `D17` (TX2) | ──▶ | `D16` (RX2) | A 板把指令发给 B 板 |
| `GND` | ──── | `GND` | 共地(必须接，否则串口通信全乱码) |

```
  A 板                          B 板
 ┌──────┐                     ┌──────┐
 │  D17 ├──────杜邦线────────▶│ D16  │
 │  GND ├──────杜邦线─────────┤ GND  │
 └──────┘                     └──────┘
```

**接线要点:**

- 板子丝印通常印的是 `D17` / `D16`(即 GPIO17 / GPIO16),不是 "TX2/RX2"
- **务必用 D17 / D16(Serial2),不要用 `TX0` / `RX0`(GPIO1/3)**——那两个被 USB 烧录占用，接了会冲突
- **TX 接对方 RX**(交叉):A 板 D17 → B 板 D16，不要 TX 接 TX
- `GND` 随便挑一个即可(板上多个 GND 内部连通),认准 `GND` 字样，**别接到 `5V` / `3V3` / `VIN` 上**
- 两块板各自用自己的 USB 供电即可，无需互相供电

**可选:蓝牙状态回传(让网页顶部圆点显示真实连接状态)**

再加一根线 `B 板 D17` → `A 板 D16`,B 板会把蓝牙连接状态回传给 A 板，网页顶部圆点即可正确显示"已连接 / 等待"。不接不影响任何控制功能，只是圆点不亮。

## 三、烧录与配置

完整的环境安装、烧录、配对步骤请见 **[Arduino_Readme.md](./Arduino_Readme.md)**。这里是速览:

1. **装环境**:Arduino IDE + ESP32 支持包 + 依赖库(异步库 `ESPAsyncWebServer`/`AsyncTCP`,以及本仓库 `libraries/` 里的修改版蓝牙库)
2. **烧 A 板**:打开 `esp32/` 里的 A 板固件,改好 WiFi 名称/密码,烧录;串口(115200)记下打印的 IP
3. **烧 B 板**:打开 `esp32/` 里的 B 板固件,烧录
4. **两块板都上电**,按下方"配对与使用"

> ⚠️ **关键**:B 板必须使用本仓库 `libraries/ESP32_BLE_Combo_Keyboard_Mouse/` 里的**修改版库**(新增了绝对定位能力),不要用原版库,否则绝对定位、点击无法工作。安装方法见 Arduino_Readme.md。

## 四、配对与使用

1. **两块板都上电**(各自 USB 供电，接线保持连接)
2. **iPhone 配对 B 板**:
   - 设置 → 蓝牙,找到 ESP32 设备并配对
   - 如果蓝牙列表里看不到,进 **设置 → 辅助功能 → 触控 → 辅助触控 → 打开 → 设备 → 蓝牙设备** 搜索
   - iPhone 的外接指针需要 **辅助触控(AssistiveTouch)** 开启才会显示光标
3. **手机浏览器打开 A 板的 IP**(和 A 板连同一个 WiFi):
   ```
   http://192.168.1.xx
   ```
   或 `http://esp32ble.local`
4. **验证**:点网页上的"回中央"，被控 iPhone 光标应移动到屏幕中央；用**屏幕映射区双击** App 图标位置，应能打开对应 App。

## 六、故障排查

| 现象 | 可能原因与解决 |
|------|----------------|
| 网页打不开 | 手机与 A 板是否连同一 WiFi;IP 是否为 A 板串口打印的最新 IP(DHCP 可能变化) |
| iPhone 搜不到蓝牙 | 到"辅助功能→触控→辅助触控→设备"里搜;之前配过的先"忽略此设备"再重搜 |
| 光标能移动但点击 / 绝对定位无效 | 确认 B 板用的是本项目**修改版库**(带绝对定位),并已重启 IDE 重新编译 |
| 改了描述符后功能失效 | iPhone **忽略此设备**后重新配对(iOS 会缓存旧 HID 描述符) |
| 网页能开但 iPhone 无反应 | 看 B 板串口:蓝牙"已连"吗?点网页时"队列积压"有跳动吗?没跳=串口没通,检查 D17→D16 接线、GND 共地、波特率 115200 |
| 蓝牙玩着玩着断了 | 本项目已内置"未连接时自动重广播",断线后 iPhone 亮屏可自动重连;若 B 板串口 uptime 归零则是重启,检查供电(换短粗好线、直插 USB 口) |
| 滚动太慢 / 方向反了 | A 板网页里滚轮量 `S:40 / S:60` 可调大;方向反了把正负号对调 |

**串口调试信息**:两块板各自 USB 都可看串口(115200)。A 板打印 `[A板存活]` + IP;B 板打印 `[B板存活]` + 蓝牙状态 + 队列积压。

## 库改动说明

本项目在原版 `ESP32-BLE-Combo` 基础上，为鼠标 HID 增加了**绝对定位(Absolute Pointer)**能力，使其可以在 iOS 上把光标定位到屏幕的绝对坐标(而非仅相对移动)。主要改动:

- **HID 报告描述符**:新增一个 `REPORT_ID = 0x04` 的 Absolute Pointer 报告,X/Y 为 16 位、逻辑范围 0~32767,映射整个屏幕
- **新增 characteristic** `inputMouseAbs`,用于发送绝对坐标报告
- **`BleComboMouse` 新增方法**:
  - `moveTo(x, y)`:绝对移动。为绕过 iOS 忽略孤立单帧绝对报告的问题,内部采用多帧插值"滑动"发送
  - `moveToWithButtons(x, y, btns)`:绝对坐标 + 按键位一起发送(点击 / 拖拽用)
  - `clickAbs()`:在最后一次绝对定位坐标处点击(按下→抬起,全程走绝对通道)

> **iOS 关键注意点**:
> - 绝对报告必须走独立的 Absolute Pointer 报告通道;点击也必须在同一绝对通道、同一坐标闭环，否则会"点空"
> - iOS 会缓存已配对设备的 HID 描述符,改动描述符后必须在 iPhone 上"忽略此设备"重新配对
> - 被控 iPhone 需开启辅助触控(AssistiveTouch)

## 指令协议(A 板 → B 板,串口)

每条指令一行,以 `\n` 结尾,格式 `类型:参数`:

| 指令 | 含义 | 示例 |
|------|------|------|
| `M:dx,dy` | 相对移动 | `M:10,0` |
| `P:x,y` | 绝对定位 (0~32767) | `P:16383,16383` |
| `Q:x,y` | 绝对定位并点击 | `Q:16383,16383` |
| `C:L` / `C:R` | 左键 / 右键点击(在最后绝对坐标处) | `C:L` |
| `S:n` | 滚轮滚动 | `S:40` |
| `T:文本` | 输入文字 | `T:hello` |
| `K:键名` | 特殊键 | `K:RETURN` |
| `H:动作` | 组合键 / 手势 | `H:HOME` |
